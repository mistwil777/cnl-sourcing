# Installer l'app CNL Admin sur ton téléphone

L'interface admin fonctionne comme une vraie application mobile —
pas besoin de passer par l'App Store ni le Play Store.

---

## Sur iPhone (Safari)

1. Ouvre **Safari** (pas Chrome, pas Firefox — uniquement Safari)
2. Va sur **https://cnlsourcing.com/fr/admin**
3. Connecte-toi avec ton mot de passe
4. Appuie sur l'icône **Partager** (carré avec une flèche vers le haut) en bas de l'écran
5. Fais défiler et appuie sur **"Sur l'écran d'accueil"**
6. Le nom "CNL Admin" est pré-rempli — appuie sur **Ajouter** en haut à droite

**Résultat :** Une icône rouge "CNL Admin" apparaît sur ton écran d'accueil.
En appuyant dessus, l'app s'ouvre en plein écran sans barre Safari.

```
┌─────────────────────────────┐
│                             │
│   ┌──────┐                  │
│   │ CNL  │  CNL Admin       │
│   │      │                  │
│   └──────┘                  │
│                             │
│  Dashboard CNL Sourcing     │
│  ■■■■■■■■■■■■■■■■■■■■■■    │
│                             │
└─────────────────────────────┘
```

---

## Sur Android (Chrome)

1. Ouvre **Chrome**
2. Va sur **https://cnlsourcing.com/fr/admin**
3. Connecte-toi avec ton mot de passe
4. Appuie sur les **3 points** (⋮) en haut à droite
5. Appuie sur **"Ajouter à l'écran d'accueil"**
   *(parfois affiché comme "Installer l'application")*
6. Appuie sur **Ajouter** dans la popup de confirmation

**Résultat :** Chrome peut aussi afficher une bannière automatique
"Ajouter CNL Admin à l'écran d'accueil" — appuie simplement sur **Installer**.

---

## Ce que tu peux faire dans l'app

| Fonctionnalité | Disponible offline |
|----------------|-------------------|
| Consulter les demandes | Oui (cache) |
| Voir les devis | Oui (cache) |
| Créer / modifier un devis | Non (connexion requise) |
| Relancer une facture | Non (connexion requise) |
| Coûts IA du mois | Non (connexion requise) |

---

## Mot de passe

Le mot de passe admin est confidentiel — il t'a été communiqué séparément.
La session dure **8 heures** puis redemande le mot de passe.

---

## En cas de problème

- **L'icône n'apparaît pas** → Vérifie que tu utilises bien Safari (iPhone) ou Chrome (Android)
- **Page blanche** → Vérifie ta connexion internet et réessaie
- **Mot de passe refusé** → Contacte le support technique CNL
