URL

Pourquoi le profil perso et pas la page entreprise pour l'instant ?

Publier sur une page entreprise nécessite une approbation de LinkedIn qui peut prendre plusieurs jours. Le système est prêt — il suffit qu'Anna clique "Demander l'accès" sur la "Community Management API" dans le portail développeur LinkedIn et d'attendre la validation.

3. L'App LinkedIn & le système OAuth2

Comment le site obtient le droit de publier sur LinkedIn au nom d'Anna.

C'est quoi OAuth2 ? (explication simple)

OAuth2 c'est le système de "connexion déléguée". C'est ce que vous utilisez quand vous cliquez "Se connecter avec Google" sur un site tiers. Vous autorisez le site à agir en votre nom, sans lui donner votre mot de passe. LinkedIn utilise exactement ce système pour autoriser le site CNL Sourcing à publier des posts à la place d'Anna.

Client ID 786am41jkdz6h6 Le "numéro de carte d'identité" de l'app (public)
Client Secret WPL_AP1.SQN··· Le "mot de passe" de l'app (à garder secret)
Person ID d'Anna x4QMGN9-qg L'identifiant unique d'Anna sur LinkedIn

Comment le token a été obtenu
1

Anna visite une URL d'autorisation

Une URL spéciale est générée avec le Client ID. Anna la visite sur LinkedIn et clique "Autoriser" pour donner accès à l'app.

2

LinkedIn retourne un code temporaire

LinkedIn redirige vers cnlsourcing.com avec un code dans l'URL (valable 10 minutes).

3

Le code est échangé contre un Access Token

Le serveur envoie le code + le Client Secret à LinkedIn. En retour, LinkedIn donne un Access Token valide 2 mois.

4

Le token est stocké dans le fichier .env du serveur

Variable : LINKEDIN_ACCESS_TOKEN. Utilisée automatiquement à chaque publication.

⚠️ À noter : le token expire dans 2 mois (début juillet 2026)

Quand le token expire, les posts ne se publieront plus et Anna recevra un message d'erreur sur Telegram. Il faudra refaire la procédure d'autorisation (environ 5 minutes). Une alerte sera envoyée sur Telegram avant l'expiration.

4. WF-11 — Le générateur automatique de posts LinkedIn

Ce workflow est le cœur de la stratégie LinkedIn. Voici exactement ce qu'il fait.

C'est quoi un "workflow" ? (explication simple)

Un workflow c'est une séquence d'actions automatiques, comme une chaîne de montage. Chaque étape fait quelque chose et passe le résultat à l'étape suivante. Les workflows du projet sont gérés par un logiciel appelé n8n, installé sur le serveur.

WF-11 en détail — étape par étape
⏰

Déclencheur automatique — Lundi, Mercredi, Vendredi à 10h30

Le workflow se lance seul à ces horaires, sans intervention humaine. C'est une horloge programmée (cron job).

📰

Récupère les 3 articles de veille les plus récents (48h)

WF-14 (un autre workflow) collecte chaque jour des articles de presse spécialisée sur le Vietnam, le sourcing et le commerce France-Asie. WF-11 pioche dedans pour nourrir le post.

💬

Récupère les insights d'Anna de la semaine

Chaque lundi matin, Anna reçoit 3 questions sur Telegram ("Comment s'est passée ta semaine ?", "Quelle anecdote fournisseur ?", etc.). Ses réponses sont stockées et utilisées ici pour personnaliser le post.

🧠

Envoie tout à Claude (IA Anthropic) pour générer le post

L'IA reçoit les articles de veille, les insights d'Anna, et un "système de personnalité" qui lui dit d'écrire comme Anna : professionnelle, directe, ancrée dans le terrain, jamais du marketing creux. Elle génère un post de 180-280 mots avec accroche, corps, CTA et hashtags.

💾

Sauvegarde le post en base de données

Le post est enregistré dans la table linkedin_posts avec le statut "en attente d'approbation". Il est lié aux articles utilisés pour éviter les doublons.

📱

Envoie la preview sur Telegram à Anna

Anna reçoit le post complet sur son téléphone avec le message : "Pour publier, réponds OK {uuid}". Elle peut lire, corriger ou valider depuis son canapé.

Résultat : 3 posts LinkedIn par semaine, entièrement automatisés

  • Lundi → post basé sur l'actualité du week-end
  • Mercredi → post au milieu de semaine
  • Vendredi → post de clôture de semaine

Anna garde le contrôle total — elle valide ou modifie chaque post avant publication.

  • LinkedIn API v2 : endpoint ugcPosts utilisé pour la publication

7. Google Search Console — Le tableau de bord Google

Ce qui a été fait pour connecter le site à Google officiellement.

C'est quoi Google Search Console ? (explication simple)

C'est le tableau de bord officiel de Google pour les propriétaires de sites. Il montre combien de personnes ont vu le site dans les résultats (impressions), combien ont cliqué, sur quels mots-clés, depuis quels pays. C'est gratuit et indispensable pour suivre le SEO.

Ce qui a été fait
1

Validation de propriété via DNS

Un enregistrement TXT a été ajouté dans le DNS de Scaleway (l'hébergeur) pour prouver à Google que le site appartient bien à CNL Sourcing. Valeur : google-site-verification=CkBHOQSF8u-M_...

2

Soumission du sitemap

Le sitemap XML a été soumis à Google : https://cnlsourcing.com/sitemap.xml. Il liste les 15 URLs du site (fr + en + vi × 5 pages) avec leurs priorités.

3

Google indexe le site progressivement

Google va visiter les 15 pages dans les 3 à 7 jours suivants et les ajouter à son index. Les premières apparitions dans les résultats suivront dans les 2 à 4 semaines.

Comment utiliser Google Search Console

  • URL : search.google.com/search-console
  • Onglet "Performance" → voir les clics, impressions, mots-clés utilisés
  • Onglet "Couverture" → voir si des pages ne sont pas indexées
  • Onglet "Sitemaps" → vérifier que le sitemap est bien traité
📈

Impressions

Nombre de fois que le site apparaît dans les résultats Google (même si personne ne clique). Augmentera progressivement sur les 3 premiers mois.

👆

Clics

Nombre de personnes qui ont cliqué sur le site depuis Google. L'objectif est d'augmenter le taux de clic (CTR) en améliorant les titres et descriptions.

🎯

Position moyenne

Rang moyen du site sur les mots-clés ciblés. Objectif : passer sous la position 10 (première page Google) sur "agent sourcing Vietnam" dans les 3-6 mois.

9. Données structurées JSON-LD — Ce que Google comprend

Un langage invisible dans la page qui explique le contenu à Google.

C'est quoi le JSON-LD ? (explication simple)

En plus du texte visible sur la page, il existe un code invisible (que seuls les moteurs de recherche lisent) qui leur explique exactement ce qu'est le site. Exemple : "Je suis une entreprise", "Mon adresse est Toulouse", "Voici mes services". Google utilise ça pour créer des résultats enrichis dans ses pages.

Les 3 types de données structurées installées
🏢

Organization + LocalBusiness

Présent sur toutes les pages. Dit à Google que CNL Sourcing est une entreprise basée à Toulouse, fondée par Anna Nguyen, qui opère en France et au Vietnam. Inclut l'email, les services proposés et le lien LinkedIn.

❓

FAQPage (page Services)

5 questions/réponses sur le sourcing Vietnam. Google peut afficher ces questions directement dans ses résultats sous forme de questions dépliables — très visible, prend de la place dans Google.

🗺️

BreadcrumbList (pages internes)

Le "fil d'Ariane" : Accueil → Services / À propos / Contact / Devis. Google affiche ce chemin sous le titre dans ses résultats, ce qui aide les utilisateurs à comprendre la structure du site.

// Exemple simplifié du bloc Organization (présent sur toutes les pages)
{
  "@type": ["Organization", "LocalBusiness"],
  "name": "CNL Sourcing",
  "email": "cnlsourcingvn@gmail.com",

  "founder": { "name": "Anna Nguyen" },
