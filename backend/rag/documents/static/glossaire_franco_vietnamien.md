# Glossaire Commerce Franco-Vietnamien

---

## Termes douaniers et logistiques

| Français | Anglais | Vietnamien | Définition |
|----------|---------|------------|------------|
| Dédouanement | Customs clearance | Thông quan | Procédure administrative pour importer officiellement des marchandises |
| Droits de douane | Customs duties | Thuế hải quan | Taxes perçues à l'importation selon le code NC du produit |
| Code NC / Code SH | HS Code | Mã HS | Code international classifiant les marchandises pour les douanes |
| EVFTA | EVFTA | EVFTA | Accord de libre-échange UE-Vietnam, en vigueur depuis août 2020 |
| Certificat d'origine | Certificate of origin | Chứng nhận xuất xứ | Document attestant qu'un produit est bien fabriqué au Vietnam |
| EUR.1 | EUR.1 | EUR.1 | Certificat d'origine pour bénéficier des taux préférentiels EVFTA |
| Connaissement | Bill of Lading (B/L) | Vận đơn | Document de transport maritime attestant la prise en charge des marchandises |
| LTA | Air Waybill (AWB) | Vận đơn hàng không | Document de transport aérien |
| Fret | Freight | Cước vận chuyển | Coût du transport des marchandises |
| MOQ | Minimum Order Quantity | Số lượng đặt hàng tối thiểu | Quantité minimale acceptée par le fournisseur |
| Incoterms | Incoterms | Điều kiện giao hàng | Termes définissant les responsabilités vendeur/acheteur dans le transport |
| FOB | FOB (Free On Board) | Giao hàng lên tàu | Le vendeur livre jusqu'au port d'embarquement, l'acheteur prend en charge le fret |
| CIF | CIF (Cost Insurance Freight) | Giá CIF | Le vendeur prend en charge fret et assurance jusqu'au port de destination |
| Groupage | Groupage / LCL | Hàng lẻ | Regroupement de plusieurs petites expéditions dans un même conteneur |
| Palette | Pallet | Pallet | Support de manutention pour regrouper des colis |
| Transitaire | Freight forwarder | Đại lý vận tải | Intermédiaire organisant le transport international des marchandises |
| Conteneur | Container | Container | Caisson métallique standardisé pour le transport maritime |
| FCL | FCL (Full Container Load) | Hàng nguyên container | Conteneur entier réservé pour un seul expéditeur |
| EXW | EXW (Ex Works) | Giao tại xưởng | L'acheteur prend en charge tout le transport depuis l'usine |
| DDP | DDP (Delivered Duty Paid) | Giao hàng đã nộp thuế | Le vendeur prend tout en charge jusqu'à la livraison finale |

## Termes business et négociation

| Français | Anglais | Vietnamien | Définition |
|----------|---------|------------|------------|
| Fournisseur | Supplier | Nhà cung cấp | Entreprise produisant ou vendant des marchandises |
| Acheteur | Buyer | Người mua | Entreprise ou personne achetant des marchandises |
| Agent sourcing | Sourcing agent | Đại lý tìm nguồn hàng | Intermédiaire facilitant la mise en relation acheteur/fournisseur |
| Devis | Quotation | Báo giá | Document précisant les prix et conditions d'une offre commerciale |
| Acompte | Deposit | Tiền đặt cọc | Versement partiel effectué avant la production ou livraison |
| Échantillon | Sample | Mẫu hàng | Exemplaire du produit envoyé avant la commande pour validation |
| Contrôle qualité | Quality Control (QC) | Kiểm soát chất lượng | Vérification de la conformité des produits avant expédition |
| Réseau | Network | Mạng lưới quan hệ | Ensemble des contacts professionnels — concept central au Vietnam (quan hệ) |
| Cahier des charges | Specifications / Brief | Bản yêu cầu kỹ thuật | Document décrivant précisément les exigences du produit souhaité |
| Délai de livraison | Lead time | Thời gian giao hàng | Temps entre la commande et la livraison finale |
| Remise | Discount | Giảm giá | Réduction accordée sur le prix de vente |
| Bon de commande | Purchase Order (PO) | Đơn đặt hàng | Document officialisant une commande avec quantités et prix |
| Facture pro-forma | Pro-forma invoice | Hóa đơn tạm | Facture préliminaire avant la commande officielle |
| Contrat | Contract | Hợp đồng | Accord légal entre deux parties définissant les obligations |

## Villes et zones industrielles clés au Vietnam

| Ville / Zone | Description |
|--------------|-------------|
| Hô-Chi-Minh-Ville (HCMV / Saïgon) | Capitale économique, hub commerce et export |
| Hanoï | Capitale politique, forte croissance industrielle |
| Đà Nẵng | Hub logistique centre-Vietnam, port en développement |
| Bình Dương | Zone industrielle majeure près de HCMV (textile, meuble) |
| Đồng Nai | Zone industrielle (électronique, chaussures) |
| Hải Phòng | Port principal du Nord, zone franche |
| Bắc Ninh | Électronique (Samsung), proche de Hanoï |
| Hội An | Artisanat traditionnel, soie, broderie |
| Bát Tràng | Village céramique historique près de Hanoï |
